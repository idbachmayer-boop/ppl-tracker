<objective>
Build the zero-dependency hash tool the CSP depends on, `scripts/csp-hash.js` with
`npm run csp:hash` and `npm run csp:check`, and pin its algorithm to what Chrome computes (D-03,
D-04, D-05). It ships inert: index.html gets no policy here, so reverting 07-04's CSP commit later
leaves this tool and its tests green.

Purpose: a hash-based `script-src` breaks the app the moment the inline script changes by one byte.
The hand-run regeneration command (D-04) and the stale-hash failure (D-03) are what make that
survivable. Both need a single hashing function that matches the browser.

synthetic temp pages.
