<objective>
Measure progress session to session and flag a stall only after 3 flat sessions in a row (PROG-02,
PROG-03). History follows `exKey` per workout and slot (PROG-04, D-04), and bodyweight sessions count
(PROG-05, D-08). Deloads, skipped days and sessions with a skipped set pause the streak (D-05, D-10). A
lighter session restarts it (D-03). Nothing is compared with the all-time best (D-06). History is
re-judged at render time, with nothing stored (D-07).

Purpose: today `isStalledSlot` compares the best single-set e1RM with the all-time maximum before the
last 3 sessions. Extra reps on sets 2 and 3 never count, so the DB lateral raise reads "stalled". A big
old PR makes the stall repeat forever, and bodyweight exercises (e1RM 0) can never stall.

Planner choice, stated so the checker and Ian can see it: a session finished after 08-01 with
`blankSets > 0` pauses the streak the same way a skipped set does. D-10 names skipped sets. D-01 counts
a blank set as not done, exactly like a skipped one, so D-10's reason applies equally: dropping a set
for time must never push Ian toward a deload warning. Older sessions have no marker, so they are judged
on what they hold (D-07).

Output: the stall helpers and the banner in `index.html`, the guide copy, the stall half of the PROG
section, and a rewritten `f2Stall` fixture.
</objective>
