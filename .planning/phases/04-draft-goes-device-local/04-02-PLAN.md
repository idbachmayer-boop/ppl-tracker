<objective>
Close every inbound door. Plan 04-01 made the sync merge and its adopt path keep the local draft.
Five more places turn foreign data into `DB` without going through that path: Import Merge, Import
Replace, restoring a local snapshot, restoring a cloud version, and the "use the cloud copy only"
choice at first link. This plan routes all of them through the helpers, proves each one, proves that
a malformed or erased cloud doc can neither crash the Log tab nor clear the workout, and adds a
tripwire so a future sixth site cannot quietly skip the rule.

Purpose: D-04 names "any merge path"; D-05, D-06, D-07 and D-08 name the rest. The research missed
both restore functions. A rule enforced at five hand-found sites is the pattern CLAUDE.md's incident
history warns about, so the tripwire is part of the deliverable.

Output: import helpers extracted from `importData()`; restores and the cloud-copy choice fixed; a
local Erase proven to clear; a malformed-cloud-draft battery; the `DB`-assignment tripwire.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Firestore doc / `versions` subcollection → `onSignedIn`, the live listener, `restoreCloudVersion` | Data from other devices and from history written before this phase; may hold a legacy or malformed `draft`. |
| a backup file on disk → `importMerge` / `importReplace` | `validateBackup()` checks shape, never the types inside (CLAUDE.md), and never the draft. A hand-edited or old file can hold anything there. |
| the local snapshot ring → `restoreSnapshot` | Entries written before this phase still carry drafts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-4-06 | Tampering | a backup file planting a draft on import | medium | mitigate | Task 1 drops the file's draft with `stripDraft()` before `normalize()` and reattaches the local one with `keepLocalDraft()`; three import tests plus an export-then-import round trip. |
| T-4-07 | Denial of Service (data loss) | a restore, import or cloud choice replacing `DB` and losing the workout mid-set | high | mitigate | Every `DB`-replacing site routes through `keepLocalDraft()` (Task 1, Task 2) and the `dbAssignLines` tripwire fails the suite on any unsanctioned new site. |
| T-4-08 | Tampering / Denial of Service | a malformed cloud draft crashing the Log tab | high | mitigate | Removed at the merge (plan 04-01), never normalized on the cloud-copy branch (Task 2), and proven for every `DRAFT_SHAPES` value on two devices through the listener and the cloud-copy choice, with the Log tab and Today drawn each time. |
