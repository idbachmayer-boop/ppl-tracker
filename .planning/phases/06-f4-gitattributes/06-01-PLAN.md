`index.html`: the versioned attribute rule, git's attribute resolution, the stored blob, and the
isolated commit. Then make this checkout's files on disk match what git stores.

on disk equal the stored bytes. The suite stays green on the LF tree.

reformat diff, and no machine's `core.autocrlf` decides what git stores.
