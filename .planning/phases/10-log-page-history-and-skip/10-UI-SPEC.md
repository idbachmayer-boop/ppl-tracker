# Phase 10 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of the visible change.** Every surface is on a **main slot card** of the active workout
(`viewActive()`), plus one line in Workout history and one control on Progress → Strength. Accessory
cards (`extraCard`) and the stair-stepper card are unchanged (RESEARCH A3).

| # | Surface | Where in `index.html` (by symbol) | Decision |
|---|---------|-----------------------------------|----------|
| S1 | Skip-exercise icon button in the card header, left of the collapse caret | `viewActive()`, the right-hand column of `.ex-head` | D-12, LOG-03 |
| S2 | Skipped card: one-line `.skip-note` with Undo | `viewActive()`, new branch before the `collapsedEx.has(i)` branch | D-08, D-11, D-13, LOG-04 |
| S3 | Tappable "Last time" line, plus the muted "skipped" note under it | `viewActive()`, the `.lasttime` element built from `lastLine` | D-06, D-07, D-17, D-24 |
| S4 | Inline history panel (last 5 sessions + chart link) | `viewActive()`, directly after S3 | D-01..D-05, D-19, LOG-01, LOG-02 |
| S5 | "Back to workout" control on Strength, and the scroll return | `viewStrength()`; `go()` / `setSub()` | D-20, D-21 |
| S6 | Skipped exercise line in Workout history | `viewHistory()`, the open row's entry lines | D-15 |
| S7 | Reason prompt copy | `skipExercise(i)` (`prompt()`, like `skipSet`) | D-10 |

The app's design system is the Nocturne `:root` tokens and the hand-written classes in the `<style>`
block. This contract reuses them, adds one icon-button class (S1) and six panel rules (S4), and adds no
colour, font or icon. Every icon used is already in the `PH` map: `skip-forward`, `caret-up`,
`caret-down`, `caret-left`, `caret-right`.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (single-file vanilla PWA, no build step; the shadcn gate does not apply, since the stack is not React/Next/Vite) |

Glyphs (named by code point; each is already used in the app for the same meaning):

- U+1F4DD (memo emoji): prefix of a logged note, as `.last-note` and the Workout history session note use it.
- U+2193 (downwards arrow, plain text, not emoji): deload marker, as in the `.coach.deload` lines.

## Spacing Scale

Declared values for new elements (multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Gap between the S1 skip button and the caret (`margin-right:4px`); S4 panel top and bottom padding; S4 link bottom padding; space before the S3 open cue |
| sm | 8px | S4 row padding (top and bottom); S4 label top padding; S4 link top padding |
| md | 16px | S5 back control `margin-bottom` before `<h1>Progress</h1>` |
| lg | 24px | Not used |
| xl | 32px | S1 minimum tap area (see Exceptions) |
| 2xl | 48px | Not used |
| 3xl | 64px | Not used |

Exceptions:
- **12px on the S4 panel:** side padding (`padding: 4px 12px`) and `margin-bottom: 12px`. Same reason as
  Phase 9's `.equip-ask`: the panel sits inside a card that runs on a 10-12px rhythm (`.lasttime` 10px
  bottom margin, `.coach` 10px), and 16px would read as a section break.
- **-4px top margin on the S4 panel**, the same tuck `.last-note` uses, so the panel reads as the
  Last time line opening downward (10px `.lasttime` bottom margin minus 4px leaves a 6px seam).
- **32 × 32px minimum tap area on the S1 skip button** (`min-width:32px; min-height:32px`), not 44px.
  A mis-tap only opens the reason prompt, whose Cancel changes nothing (D-10), so the cost of a miss is
  one dismissal. 44px would push the header row taller on every card on a 380px phone. The visible icon
  stays 15px (`.skip-set .ph`), the same as the caret beside it.
- **Inherited, not re-specified:** `.ex-body` 14px padding, `.lasttime` 7/9px padding and 6/10px margins,
  `.skip-note` 7/9px padding, `.hist-detail` 4/10px padding, `.btn-sm` 6/11px. This phase does not
  touch them. S2 keeps the stair card's `style="margin:0"` on its `.skip-note`.

**Width check at about 380px (Ian's phone).** Card content width is about 318px (380 − 2×16 container −
2×1 border − 2×14 `.ex-body`). The `.ex-head` right column (`text-align:right; white-space:nowrap`)
holds, left to right: S1 skip (32px + 4px gap), caret (about 27px), a space, and the range badge (about
68px for "8–12 reps"): about 135px, leaving about 175px for the muscle/movement/how-to meta, which
already wraps. When the ⬆ Add weight flag shows, it sits on its own line in that column and is wider
than the first row, so S1 adds no width in that case. Because the column is right-aligned and S1 is its
**leftmost** item, hiding S1 (D-12) moves neither the caret nor the badge.

New text uses 2 sizes and 2 weights. Text it sits beside keeps its existing styles.

## Component Inventory

**Focal point.** On an ordinary card the set rows stay the focal point, and nothing in this phase adds
weight to them. When a panel is open (S4), it is the card's focal point: the only bordered inset on the
card. A skipped card (S2) is deliberately the quietest card in the list: one muted line, so the eye
moves past it to the next exercise.

### S1 — Header skip button (new markup, one new class)

New rule, in the `<style>` block next to `/* Exercise log card */`:

```css
.ex-skip { min-width: 32px; min-height: 32px; margin-right: 4px; vertical-align: middle; }
```

Markup, first item in the `.ex-head` right-hand column, before the existing caret:

```html
<button class="skip-set ex-skip" data-action="skipExercise" data-i="{esc(i)}"
        title="skip this exercise" aria-label="Skip this exercise" style="font-size:16px">{ph('skip-forward')}</button>
<button class="skip-set" data-action="toggleExCollapse" …>{ph('caret-up')}</button>   (existing, unchanged)
<span class="range-badge">…</span>{flag}                                              (existing, unchanged)
```

- **Shown only when** the card has at least one unfinished set: a set that is neither done (reps
  entered) nor already skipped. Evaluated at render. Typing the last reps does not re-render, so the
  button can stay until the next render; tapping it then does nothing (the function re-checks and
  returns).
- Uses class `skip-set` for colour and icon size, never `tap`, and never `data-action="toggleExCollapse"`
  (the header-caret test locator, RESEARCH Pitfall 7).
- `data-action` is the literal `skipExercise`.

### S2 — Skipped card (new branch, existing classes)

Checked **first** for each slot, before the collapsed branch. Mirrors the skipped stair-stepper card:

```html
<div class="ex-card"><div class="ex-accent {barClass(g)}"></div><div class="ex-body">
  <div class="skip-note" style="margin:0"><span>{ph('skip-forward','lead')}<strong>{esc(name)}</strong> · {tail}</span><button data-action="unskipExercise" data-i="{esc(i)}">Undo</button></div>
</div></div>
```

- The opener is exactly `<div class="ex-card">` (tests split cards on it, RESEARCH Pitfall 2). No
  modifier class on the card.
- The card keeps its workout-colour accent bar, so its slot is still recognisable in the list.
- No caret, no set rows, no Last time line, no panel, no note input. The `.skip-note` flex layout keeps
  Undo on the right; a long name, set list or reason wraps inside the left `<span>` and Undo stays
  `white-space:nowrap`.
- Precedence: a skipped card ignores `collapsedEx` and `openExHist` but never clears them. After Undo
  the card comes back collapsed or expanded, with or without its panel, exactly as it was.
- `data-action` is the literal `unskipExercise`, in its own template (never chosen at runtime).

### S3 — Tappable Last time line (changed markup) and the skipped note (new)

When the line has real history (`ref || alt`):

```html
<button class="lasttime tap" data-action="toggleExHist" data-i="{esc(i)}" aria-expanded="{true|false}">
  {lastLine}<span class="muted" style="font-size:12px;margin-left:4px">{ph(open ? 'caret-up' : 'caret-down')}</span>{skippedNote}
</button>
```

When it has none (D-07, D-24): the existing plain element, `<div class="lasttime">{lastLine}{skippedNote}</div>`.

`{skippedNote}`, only when the most recent attempt **in this slot** (`lastAttemptEntry`) has
`entry.skipped === true`:

```html
<span class="muted" style="display:block;font-size:12px">{ph('skip-forward','lead')}Skipped {date}: <em>{esc(reason)}</em></span>
```

- The button holds only `<span>`, `<strong>`, `<em>` and `<svg>`, never `<div>` (RESEARCH Pitfall 4).
  `.last-note`, the coach line and S4 stay outside it.
- `:where(button.tap)` gives the button block display, full width and inherited text alignment with zero
  specificity, so `.lasttime`'s background, padding, radius and margins still apply. It looks the same
  as today's line, plus the cue.
- `aria-expanded` is `"true"` only on the one open card.
- The skipped note sits on its own line inside the box, under the numbers, so the pinned Last time text
  is untouched and the note never wraps into the middle of it.

### S4 — Inline history panel (new; six new CSS rules)

```css
.exh { background: var(--surface-2); border: 1px solid var(--border); border-radius: 8px; padding: 4px 12px; margin: -4px 0 12px; }
.exh-label { font-size: 12px; line-height: 1.5; color: var(--muted); padding: 8px 0 4px; }
.exh-row { font-size: 12px; line-height: 1.5; color: var(--text-2); padding: 8px 0; border-top: 1px solid var(--border-3); }
.exh-date { font-weight: 600; color: var(--text); }
.exh-note { display: block; color: var(--muted); }
.exh-link { display: block; width: 100%; text-align: left; background: none; border: none; border-top: 1px solid var(--border-3); color: var(--link); font-family: inherit; font-size: 12px; font-weight: 600; cursor: pointer; padding: 8px 0 4px; min-height: 32px; }
```

Markup, directly after S3 and before `.last-note` / the coach line, only on the card whose slot equals
`openExHist`:

```html
<div class="exh">
  <div class="exh-label">Last 5 sessions · any workout</div>
  <div class="exh-row">
    <span class="exh-date">Oct 8</span> · <span class="muted" style="font-size:12px">PUSH 1</span> — 135×10, 135×9 {U+1F3C6}, 135×8<span class="muted" style="font-size:12px"> ↓ deload</span>
    <span class="exh-note">{U+1F4DD} {esc(note)}</span>
  </div>
  … up to 5 rows, newest first …
  <button class="exh-link" data-action="openExChart" data-i="{esc(i)}">Full chart in Strength {ph('caret-right')}</button>
</div>
```

- Rows come from the new pure helper over `liveSessions()` (RESEARCH Pattern 3): this exercise by
  `exKey`, any workout or slot, newest first, at most 5, deloads and skipped attempts included, deleted
  sessions and skipped days excluded, the session being edited excluded.
- The panel never contains the string `class="ex-card"`.
- With no rows: the label is omitted and one `<div class="exh-row" style="border-top:0">` reads the S4
  empty copy (it is the panel's first child, so it takes no divider). The link still renders, so
  Strength is reachable.
- Rows are not tappable. Only the link is a control, and it is a `<button>` (DELEG-06).
- The panel follows the slot, not the exercise: if Ian swaps the slot's exercise with `pickEx` while the
  panel is open, it shows the new exercise's rows.
- The first `.exh-row` after `.exh-label` keeps its top border; it divides the label from the rows.

### S5 — Back to workout (Strength) and the return

Markup, the first thing `viewStrength()` returns, above `<h1>Progress</h1>`, in **both** the populated
branch and the "no data" branch, only while a return point is set and a draft exists:

```html
<button class="btn btn-ghost btn-sm" data-action="backToWorkout" style="margin-bottom:16px">{ph('caret-left')}Back to workout</button>
```

- Not shown on Progress → Weight, Volume, Cardio or the pet tab. Train → Log works from anywhere.
- Shown only after following the S4 link. Arriving at Strength any other way shows no control.
- Arrival at Strength: the exercise is selected in the existing `<select data-action="selectExercise">`
  (its `exKey`, or its "(reps)" option for bodyweight). If it has no chartable data, Strength opens on
  its default, as it does today, with no message.

### S6 — Workout history line (changed markup in an existing component)

Inside the open `.hist-detail`, an entry with `skipped === true` renders
`<strong>{esc(name)}</strong> — <span class="muted">{tail}</span>{deload/note parts as today}` instead of
the per-set list. Entries without the marker keep today's line, including `<em>skip</em>` for single
skipped sets. Older builds on another device keep showing the per-set `<em>skip</em>` form; that is
expected.

## Interaction Contract

| Interaction | Event → `ACTIONS` entry | Calls | Persists | Feedback |
|-------------|-------------------------|-------|----------|----------|
| Tap the S1 skip icon | `click` → `skipExercise` (`+el.dataset.i`) | `skipExercise(i)`: prompt S7; Cancel returns with no change | `saveLocal()` only (draft) | `render()`: the card becomes S2. No toast |
| Answer the prompt with nothing | (same) | Skips with an empty reason | `saveLocal()` | S2 reads `{name} · skipped` |
| Tap S2 Undo | `click` → `unskipExercise` (`+el.dataset.i`) | Restores the pre-skip snapshot exactly (weights, typed values, earlier single-set skips and their reasons, deload) | `saveLocal()` | `render()`: the full card returns with its previous collapse and panel state |
| Tap the S3 line | `click` → `toggleExHist` (`+el.dataset.i`) | Sets the open slot, or clears it if it was this one | **none** (screen-only state) | `render()`: S4 opens under the line, any other open panel closes, the cue flips, `aria-expanded` updates. The page does not scroll |
| Tap the S3 line again | (same) | Clears the open slot | none | Panel closes |
| Tap S4 "Full chart in Strength" | `click` → `openExChart` (`+el.dataset.i`) | Records the Log scroll position (`window.scrollY \|\| 0`), selects the exercise, opens Train → Progress → Strength | none | Strength renders at the top with the exercise charted and S5 showing |
| Tap S5 "Back to workout" | `click` → `backToWorkout` | `goSub('train','log')` | none | Log tab at the recorded scroll position, the same panel open, collapsed cards still collapsed, every set unchanged |
| Train → Log via the section switcher after the link | existing `setSub` | existing | none | Same as Back to workout. The return point is used once, then cleared |
| Any later arrival at the Log tab | existing | existing | none | Scrolls to the top, as today |
| Finish & save with a skipped exercise | existing `finishWorkout` | Keeps per-set `skipped` flags and the entry marker, strips the draft-only snapshot | `save()` (existing, the one sanctioned path) | Existing finish flow. A workout where every exercise is skipped finishes normally (D-16) |
