<objective>
Ian can skip a whole exercise mid-workout with one optional reason, undo it exactly, keep it through an
app reload, and finish the workout with the skip recorded, so the next time that exercise comes up the
app does not suggest adding weight to it.

Purpose: the skip is the half of Phase 10 that writes data. It is a draft edit until finishWorkout
writes it into the synced session, and that session is read by every device and every backup from then
on (D-09). The per-set `skipped` flags stay the source of truth, so Add weight, stall, PRs, volume and
the export handle a skipped exercise with no change, and older builds on another device do too.

- `index.html`: four new functions, the S1 button and the S2 card branch in viewActive, the finishWorkout
  strip, two ACTIONS entries and one CSS rule.
- `test/app.test.js`: the new LOG section, plus the two DRAFT-05 rows.

</objective>

<assumption_delta_decision>
- **Primary noun:** a session entry, meaning one exercise on the workout card, in the draft and in a
  finished session.
- **Decision:** `add-alongside`.
- **Rationale:** the exercise-level `skipped: true` plus `reason` is a display marker added beside the
  per-set `skipped` flags. The per-set flags stay the only source of truth for every judgement (Add
  weight, stall, PRs, volume, the export), and the entry's identity (`exKey`) does not change, so old
  builds and every existing reader are unaffected.
- **Interaction with the per-set skip shape:** sets the exercise skip marks get a per-set reason of
  ''. The exercise reason lives once on the entry. A set skipped earlier keeps its own reason, which
  is what lets Undo without a snapshot tell the two apart (D-25).
- **What would force a later promote:**
  - a judgement that must treat "skipped as a whole" differently from "sets skipped one by one", for
    example a stall rule that ignores whole-exercise skips;
  - the marker and the per-set flags disagreeing in real data, for example an older build re-saving an
    edited session drops the marker, which would make the marker unfit as a source of truth.
- **Invariant tests (Task 3):**
  - deleting the marker from a finished entry changes neither addWeightInfo nor stallStreak;
  - every entry this build writes with `skipped === true` holds at least one set with `skipped === true`.
</assumption_delta_decision>

<interfaces>
These signatures were checked against the real code at plan time.

- `exUnfinished(e)` returns an array. If `e` is falsy or `e.sets` is not an array, it returns `[]`.
  Otherwise it returns `e.sets.filter(st => st && typeof st === 'object' && !st.skipped && st.r === '')`.
- `skipExercise(i)`:
  - `const e = DB.draft && DB.draft.entries[i]`. Return with no prompt when `!e`, when
    `e.skipped === true`, or when `exUnfinished(e).length === 0`.
  - `reason = prompt(\`Why skipping ${e.name}? (optional)\`, '')`. Return on `null`.
  - `e._preSkip = { sets: JSON.parse(JSON.stringify(e.sets)), deload: !!e.deload }`.
  - For each set in `exUnfinished(e)`: `skipped = true`, `reason = ''`, `w = ''`, `r = ''`.
  - When no set with `!x.skipped && x.r !== ''` remains, set `e.deload = false` (D-22).
  - `e.skipped = true`, `e.reason = String(reason).trim()`, then `saveLocal(); render();`.
- `unskipExercise(i)`:
  - `const e = DB.draft && DB.draft.entries[i]`. Return with no write when `!e` or `e.skipped !== true`.
  - When `e._preSkip` is an object whose `sets` is an array of objects, run
    `e.sets = e._preSkip.sets; e.deload = !!e._preSkip.deload`.
  - Otherwise, for each set `st` at index `k` with `st && st.skipped && !st.reason`: `skipped = false`,
    `reason = ''`, `r = ''`, and `if(st.w === '' || st.w == null) st.w = nearWeight(e.sets, k)`.
  - Then `delete e._preSkip; delete e.skipped; delete e.reason; saveLocal(); render();`.
- `skipTailHTML(e, prAt)` returns an HTML string with no name:
  - `done` is the list of `{x, k}` over `e.sets` (an array guard first) with `x && !x.skipped && x.r !== ''`.
  - `sets` is `done.map(({x,k}) => esc(fmtSet(x.w, x.r)) + (prAt && prAt(k) ? ' ' + TROPHY : '')).join(', ')`.
    TROPHY is the same glyph viewHistory's `setsOf` appends, U+1F3C6.
  - `why` is `e.reason ? ': <em>' + esc(e.reason) + '</em>' : ''`.
  - It returns `${sets} · rest skipped${why}` when `done.length`, else `skipped${why}`.
- S2 markup, verbatim from 10-UI-SPEC.md § S2:
  `<div class="ex-card"><div class="ex-accent ${barClass(g)}"></div><div class="ex-body"><div class="skip-note" style="margin:0"><span>${ph('skip-forward','lead')}<strong>${esc(entry.name)}</strong> · ${skipTailHTML(entry)}</span><button data-action="unskipExercise" data-i="${esc(i)}">Undo</button></div></div></div>`.
- S1 markup, the first child of the header's right-hand column:
  `${exUnfinished(entry).length ? \`<button class="skip-set ex-skip" data-action="skipExercise" data-i="${esc(i)}" title="skip this exercise" aria-label="Skip this exercise">${ph('skip-forward')}</button>\` : ''}`.
  The UI checker allowed dropping the inline font-size, because `.skip-set` already sets 16px.
