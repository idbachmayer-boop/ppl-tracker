<interfaces>
- `ladderStep(name, x) → number`. It is `weightStep(name, x)`, with null (bodyweight) mapped to 2.5
  (RESEARCH A5: a belt load moves in 2.5s).
- `loadFloor(name, x) → number ≥ 0`: the largest ladder value ≤ x. In lb, a dumbbell uses 2.5
  multiples below 60 and 60 + 5 multiples from 60. Everything else (and kg) uses multiples of
  ladderStep. Every division carries +1e-9 inside the floor.
- `loadNearest(name, x) → number`: lo = loadFloor(name, x), hi = lo + ladderStep(name, lo). Returns lo
  when (x − lo) ≤ (hi − x) + 1e-9, so ties go down.
- `deloadBaseW(workout, slotIndex, exName) → number`: the heaviest worked weight of
  `lastRealEntry(workout, slotIndex, exName) || lastAnywhere(exName)`, by setWeightNum. 0 when there is
  none.
- `deloadPlan(name, lastW) → { w, atBar }`:
  - lastW not > 0 → `{ w:'', atBar:false }`;
  - in lb with `barWeight(name) > 0` and lastW ≤ bar (+1e-9) → `{ w: lastW, atBar:true }`;
  - otherwise x = loadFloor(name, 0.9·lastW), which is always strictly below lastW (D-11); x not > 0 →
    `{ w:'', atBar:false }`;
  - in lb, when a bar exists and x < bar, x = bar;
  - return `{ w:x, atBar:false }`.
- `warmRampHTML(entry) → string`: the inner HTML toggleWarm writes today, rebuilt on the helpers above.
</interfaces>
