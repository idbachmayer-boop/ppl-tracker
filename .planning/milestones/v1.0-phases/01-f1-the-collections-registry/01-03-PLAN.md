## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cloud blob → local merge | every sync is a Firestore `runTransaction` that re-reads the remote blob (possibly written by a stale or older device) and calls `mergeDB()` |
| deliberate replace → union engine | Erase all data and Import→Replace bump `gen` specifically to escape the union |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Tampering | The gen-mismatch replace gets folded into the loop, so Erase all and Import→Replace are silently undone on the next sync | high | mitigate | Task 2's textual block check and early-return ordering check, plus Task 1's named zero-survivor test in both argument positions |
| T-01-09 | Tampering | A map collection merged by key-union resurrects unchecked boxes forever | high | mitigate | collectionProblems refuses the declaration (plan 01-01). mergeCollections throws on an unknown strategy. Replays for explicit false, absence and inner keys run on both maps |
| T-01-10 | Denial of service | mergeCollections throws inside a sync transaction because of a bad strategy, which aborts that push. Local data is untouched | low | accept | The boot-time collectionProblems check stops such a registry from ever booting. The only remaining path is runtime mutation, and the REG-01 snapshot test forbids that |
| T-01-11 | Tampering | Key derivation drifts (a string key versus the hand-written arrow), which orphans or duplicates rows | high | mitigate | Per-list replays built from ROW_FOR rows and the pre-id sessions replay here.
