   - GOLDEN_PATH is path.join(__dirname, 'fixtures', 'merge-golden.json').
   - WRITE is true when process.env.WRITE_MERGE_GOLDEN equals '1'.
   - GOLDEN_IN is the parsed file when it exists, otherwise {}. GOLDEN_OUT starts as {}.
   - `golden(label, legacyText, derivedText)`: when WRITE is set, it stores fnv1a(legacyText) under the label in GOLDEN_OUT. Otherwise, when the golden file exists, it adds the ok "golden: " plus the label, requiring GOLDEN_IN[label] to equal fnv1a(derivedText). The extra is 'no golden recorded for this label' when the label is missing, otherwise 'hash differs'. A missing label fails, so a new case must be recorded deliberately.

   - 'random:' plus the index plus ':' plus lw, for the random battery
   For the generated validate battery and the random battery, aggregate the checks into one ok each: "golden: validate battery — derived answers match the recorded legacy answers" and "golden: random battery — 400 derived merges match the recorded legacy merges". The extra is the mismatch count and the first mismatching label.
