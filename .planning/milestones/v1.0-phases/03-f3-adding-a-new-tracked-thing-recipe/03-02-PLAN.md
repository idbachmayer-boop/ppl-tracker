<objective>
Build Dry Run A: a permanent, `npm test`-verified rehearsal of the recipe's data-layer half, using a
throwaway map-shaped collection declared in exactly one injected line.

Purpose: DOC-04 asks that the recipe be verified end to end for a collection that is not `sleep`.
`sleep` is list-shaped, so Phase 1's coverage never exercised the six map-only branches of
`collectionProblems()`, nor `merge:'replace-whole'`, nor `explicitFalse` — which is precisely the
hole `mobilityLog` fell into. A map-shaped probe tests strictly more of the recipe than another
list-shaped one would, and riding `test/harness.js`'s existing `opts.transform` mechanism makes the
rehearsal permanent and unable to bit-rot, unlike a discarded branch.

Output: a new `test/app.test.js` block proving a map-shaped collection reaches every derived consumer
from its declaration alone.
</objective>
